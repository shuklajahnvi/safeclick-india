# SafeClick India
Static responsive website for the CSET489 SEO mini-project. Uses HTML, CSS and JavaScript with no build step.

## Files
- `index.html` — main website with scam guides, account security, safe payments, official reporting resources and blog cards
- `assets/styles.css` — responsive styles
- `assets/site.js` — mobile navigation
- `assets/favicon.svg` — site icon
- `robots.txt` and `sitemap.xml` — basic crawl files

## Deploy on GitHub + Vercel
1. Extract the ZIP.
2. Create a GitHub repository, then upload `index.html`, `robots.txt`, `sitemap.xml`, and the `assets` folder to the repository root.
3. In Vercel choose **Add New → Project**, import that GitHub repository, and deploy. This is a static site; no build command is needed.
4. After deployment, replace `YOUR-VERCEL-URL.vercel.app` in `robots.txt` and `sitemap.xml` with the exact Vercel hostname, commit and push again.
5. Test the site on desktop and mobile and click every internal/external link.

The site is an educational project, not a government service. Verify official resources before submission. Do not claim search rankings or performance scores until measured.
